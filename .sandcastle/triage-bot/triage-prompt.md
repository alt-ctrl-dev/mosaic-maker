# TRIAGE TASK

Triage GitHub issue #{{ISSUE_NUMBER}}: {{ISSUE_TITLE}}

Load the /triage skill. Use `docs/agents/triage-labels.md` for the label mapping.

You are the decision-maker here. There is no maintainer to consult. Assess the issue and act.

## Decision

After gathering context (issue body, comments, codebase, `.out-of-scope/`), choose one path:

**Path A — Not enough information to act.**
Label the issue `needs-info`. Post a comment asking the reporter specific, actionable questions. Use the needs-info template from the triage skill.

**Path B — Enough information to act.**
Decide whether the work is suitable for an agent or requires a human. Label accordingly (`ready-for-agent` or `ready-for-human`). Post an agent brief following `.agents/skills/triage/AGENT-BRIEF.md`.

In both cases, also apply the appropriate category label (`bug` or `enhancement`). Remove any conflicting state labels.

## Rules

- Every comment must begin with: `> *This was generated by AI during triage.*`
- Work only on issue #{{ISSUE_NUMBER}}.
- Do not implement the requested change.
- Do not edit source code or repository files.
- Do not make git commits.
- Do not close the issue.
- If prior AI triage notes exist and nothing has changed since, make no duplicate comment. Output <promise>COMPLETE</promise> immediately.
- Never post both ready-for-agent and needs-info

When done, output <promise>COMPLETE</promise>.
